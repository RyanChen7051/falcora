  · MapYourShow remote-proxy（CES 2027，3,128 家，源本身无电话/邮箱）
  · goexposoftware（SHOT Show 2027，2,578 家，源本身无电话/邮箱）
· 合计 75,180 家 / 106 个展会 / 132 个国家（同名同国已去重，同一公司参展多站会合并）。
· 个人联系方式（姓名、个人邮箱、手机号）已在采集端剔除：`exhibitor.contacts` 整段不读取；手机号按号码冠号判据丢弃（中国/德国明确判据，其他国家不判以免误杀座机）；人名邮箱按职能词白名单过滤。累计剔除手机/无效电话 7,982 条、人名邮箱 12,700 条。属 L3，只能使用者自备。
· 参展商是供货方，用途是「企业真实性证据」+「供应链情报」，不是客户名单。
· CES / SHOT Show 两家源本身不公开电话与邮箱，所以这两族「有电话」为 0 —— 这是源的限制，不是没抓。需要联系方式请走 L2 官网提取流程。
· 未命中 ≠ 企业不存在，只等于「不在本名录内」。
政府采购单位（第三来源）数据边界
· 来源：TED 欧盟招标开放接口（api.ted.europa.eu/v3/notices/search，无需 key）， 取 buyer-name / buyer-internet-address / buyer-email / organisation-tel-buyer 四个字段，全部取自招标公告正文。
· 规模：1,763 家采购单位（政府 / 军警 / 国防采购机构），覆盖 3,913 条公告；国家前五 PL 381 / DE 187 / RO 146 / FR 144 / ES 96。
· 官网可达性已实测（2026-11-03，1,220 个唯一域名 / 1,506 家）：✓ 可达 841 · ⚠ 有应答但拦截或异常 168（403/429 反爬照收）· ✗ 无响应 495 —— 无响应 = 可能失效，也可能是反爬拦截，不排除误判；另有 2 家命中本机过滤页劫持，无法验证。55 家仅 http 可打开（已存实测 URL）。逐条以实测标注为准；网络环境不同结果可能不同。
· ⚠️ 不含个人联系方式：公告里的 buyer-contact-point 常为个人姓名（如 Catalin IONESCU），已整段丢弃； 邮箱按「多段全字母 = 个人」剔除 303 条个人邮箱，只保留机构/职能邮箱（属 L2）。
· ⚠️ TED 全文检索为模糊匹配，含少量非采购类机构（市政 / 教育，约 38 家），每条可点「招标数」列的公告链接核实。
· 这是采购方（买方），与上面 75,180 家参展商（供货方）永不合并；也不进 02 页采购方池，除非你手动「加入管线」。
