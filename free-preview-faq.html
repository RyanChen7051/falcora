公开体验版能试什么，正式情报包包含什么

一句话：先试方法，再买证据

不用注册、不用付款，打开公开体验版就能直接操作。免费的部分是「怎么查」——真实名录的检索手感、三态输出的含义、每条结论为什么必须带来源。付费的部分是「查完之后能拿走什么」——一份逐条可点开复核、可离线保存的情报包。

目前 FALCORA B2B 只有一种商业化形态：按次交付情报包。没有订阅套餐，没有试用期账号，没有在线支付，也没有账户权限判断。

权限提示的真实含义

体验页上「付费用户使用」是一句功能说明，点选只弹出解释与联系方式，不是账户鉴权，也不会返回任何被锁的数据。这一层刻意做轻，是因为现在没有后端，不该让访客误以为存在一套账号系统。

未付费访客看到的界面

公开体验版是一页式界面，从上到下四个区块，可索引、可直接分享：

  1. 页首声明：标题「先查清楚，再去谈 · 现在可以试」，以及一段金色边界提示——只加载 L1 采购方公开名录，不加载企业职能联系方式明细与三名录反向索引；体验版不填入实际核验值、不生成尽调结论、不判「无风险」。
  2. 试检索区：一个关键词输入框、一个自动生成的行业族下拉、一个「检索」按钮，下方实时显示「命中 N 家 / 名录共 398 家 · 显示前 12 家（仅 L1 公开信息）」。
  3. 付费门禁区：六张功能卡，每张带「付费用户使用」标签，点选弹出说明。
  4. 数据边界与联系方式：L1 / L2 / L3 分层、供货方 ≠ 采购方、三态输出、实测口径，以及 WhatsApp 与两个邮箱。

页首与页尾还有「产品介绍 / English / 样品情报包」导航。也就是说，整组对外页面（中英落地页、三篇核验指南、中英样品情报包、体验版）都对未付费访客开放；内部产品样机不在这条路径上。

可以直接试的四件事

  • 检索 398 家真实采购方 L1 名录：可输入公司名、域名、国家或行业关键词，也可切换行业族，回车与按钮都能触发；支持 ?q= 直接带关键词进入。输入 US 这类两位国家码时按国家字段精确匹配，不会把 us 当子串误命中无关公司。
  • 看结果卡：公司名、可点开的官网链接，以及国家、地区、行业、类型四个标签。查不到时文案是「检索不到不代表企业不存在」。
  • 展开核验维度框架：企业身份、官网可达性、名录交叉验证、L2 来源、三态结论共五条维度。这里只列该查什么，不填任何实际值，也不对任何一家公司下判断。
  • 读数据边界与样品情报包：边界卡写清 L1 / L2 / L3、三态、平台绝不填示例值，以及 398 家的实测口径（域名可达 261 / 拦截 128 / 无响应 9）；样品情报包可打开一份完整的交付样例，看正式报告长什么样。

检索每次显示前 12 家，这是公开体验版的展示上限，不是企业总数；正式情报包不受此限制。

挑选标准很简单：能证明数据是真的、能讲清方法论的开放；能直接拿走结论、能直接变现、或属于内部工作台的锁住。

为什么名单免费查，情报包要按次交付

公司名、官网、国家与行业本来就是公开信息，把 L1 名单藏起来既不现实，也不是产品价值所在。真正费工、也真正能用于交易决策的是证据链：逐条带来源链接与检索日期的 L2 企业职能联系方式、三类独立名录的交叉命中记录，以及查到 / 查到但无值 / 查不到的三态结果。

查不到就如实标注，不拿别的来源补位、不猜邮箱、不编值，更不输出「无风险」或风险评分。判断权始终留给你，这也是「每条结论都能点开复核」比「名单更多」更值钱的原因。

正式情报包包含什么

企业基本信息、L2 企业职能联系方式（逐条带 src 与检索日期）、名录交叉验证结果、你自备的联系人（如有）、数据边界声明，打包成一份可离线打开的 HTML。样品情报包展示的就是这个形态。
